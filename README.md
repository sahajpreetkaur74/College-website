# College-website

Riverside Institute Of Technology website (no backend)

Open index.html (double-click it). That's all.

All forms work: registration, login, contact, admissions enquiry and feedback.
The data is saved inside your browser (demo mode), so it stays on your own computer.

Tip: use Google Chrome or Microsoft Edge. Some Firefox settings stop pages that are
opened as files from sharing saved data, which can make login fail after registering.
